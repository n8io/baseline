Each context is tested through its interface. The Template's Foo tests build the context as the composition roots do, `contextsCreate(connections).fooContext` on memory connections, and call its Use cases, mount its routes, run its schedule and seed, asserting on what comes back and on a later read instead of on memory state. What leaves the context is watched at the connection it leaves through (a recording `analytics`, `liveHub` or `cacheStore` spread into the connections), and Domain events are checked on Postgres through the interface in `foo-transaction.postgres.test.ts`. Only the repository contract, the transaction's commit and rollback, the Postgres races and `application/bar-list.postgres.test.ts` (a foo's bars go with it, which no read can show) still look behind the interface. The memory ports no longer record what analytics and live updates were given. Deleted as repeats: `domain/foo.test.ts` (its two scope cases moved into the update and delete tests), `adapters/outbound/index-foo.test.ts` and `application/foo-use-cases-queue.test.ts`. `Connections` now carries the `clock` (`connectionsOpen` gives the system clock), and each context's `adapters/outbound/index.ts` reads it, so a test sets the time with `{ ...connections, clock: clockMemoryCreate(now) }`. `aggregate-create` copies tests in this shape. New `docs/agents/tests.md`; `apps/app/AGENTS.md` `## Tests` states the rule.

To upgrade a Project: after `pnpm template-upgrade`, and before the next `pnpm aggregate-create` (its new tests set the time through the connections), in each context's `adapters/outbound/index.ts` change `<context>Clock: clockSystemCreate()` to `<context>Clock: connections.clock` and drop the `clockSystemCreate` import; any test that builds a `Connections` by hand adds `clock`. The Project's existing tests keep passing. Move them to the interface as you touch them: replace `<context>UseCasesCreate(<context>PortsMemoryCreate().ports)` with `contextsCreate(connections).<context>Context.useCases`, and each assertion on `state` with a read through a Use case. Delete `adapters/outbound/index-<aggregate>.test.ts` and `application/<aggregate>-use-cases-queue.test.ts` once their cases sit in interface tests (`docs/agents/tests.md`). `app@<this version>:apps/app/src/contexts/foo/` shows the shape.
