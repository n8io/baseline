The queue follows the shared Package rules. Breaking: `Queue.stop()` is `close()`, the name every Package's own handle closes with; `queueEventsMemoryCreate` is `queueEventsPublisherMemoryCreate`, named for the port it fills, and a contract test now runs the same cases against it and the queue's own publisher; `queueMigrate` and `queueSchedulesSync` throw on a `vendor` key other than `ssl`, `application_name` and `options`, and on `vendor.ssl` beside an `ssl…` parameter in `databaseUrl`, as `postgresMigrate` does; and the path for releases before 8 is gone (a worker no longer drains an unordered `<queueName>` queue and `queueMigrate` no longer deletes one), so a Project on 7 or earlier upgrades to 8 first and runs it for a week. A bad option's `TypeError` message starts with the function's name. Each options object has an exported type (`QueueOptions`, `QueueMigrateOptions`, `QueueSchedulesSyncOptions`, `QueueSchedulesStartOptions`, `QueueScheduleOptions`, `QueueConsumerOptions`, `QueueEventsPublisherMemoryOptions`), and an optional field also takes `null` for its default. README "Upgrading to 9" lists each step.
