Tools are quieter and faster. `glossary-check` reads only comments and string literals in code (it skips migrations, JSON, JSX element names and `kind:` values), so it stops warning about identifiers. `pnpm check` runs `varlock codegen` and `react-router typegen` (after wiping `.react-router/types`), then Biome and `tsc`, and reports both before it exits non-zero; `pnpm format` is `biome check --write .`. Domain tests run in their own `unit-domains` Vitest project that shares one module graph (`isolate: false`), so the unit job fits its budget with many Domains. `lucide-react` is a dependency (the icon library `components.json` names), and `piece-remove ui` removes it. `.env.development` no longer sets `OTEL_EXPORTER_OTLP_ENDPOINT` (no collector runs by default; set it in `.env.development.local` with `--profile telemetry`). The telemetry integration tests set `OTEL_SDK_DISABLED=false` for their processes. Biome's `useMaxParams` is off for `*.test.ts(x)` and `*-test-*.ts`. Integration setup stops with "build/ is older than src/..." when a source file is newer than the build. Green runs print no error-level lines.

To upgrade a Project: take `scripts/glossary-check.ts`, `scripts/check.ts`, `scripts/template-render.ts` and `scripts/template-upgrade.ts` from the Template, set `check` to `node scripts/check.ts` and `format` to `biome check --write .`, add the `unit-domains` project from the Template's `vitest.config.ts` (exclude `src/domains/**/*.test.ts` from `unit`) and `--project unit-domains` to the `test` script, add `lucide-react`, add the `overrides` entry to `biome.json`, and remove the `OTEL_EXPORTER_OTLP_ENDPOINT` line from `.env.development` if no collector runs.
