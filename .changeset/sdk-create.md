Add `@n8io/baseline-sdk`: the fetch a Project's generated SDK calls, in Node and browsers. `sdkFetchCreate({ defaults?, environments? })` returns `{ sdkConfigure, sdkFetch }`, one instance per SDK, so two SDKs in one app keep their own environments and token. A caller picks an environment by name (`sdkConfigure({ environment: "production" })`, typed, so a misspelt name does not compile) instead of a URL; there is no default, and `baseUrl` stays as an override for tests, worktrees and one-off servers. Every call has a timeout per attempt (`timeout`, 10 s) and one for the whole call (`totalTimeout`, 30 s), and a GET, HEAD or DELETE is sent again (`retry`, 2; `0` turns it off) after a network failure, a timed-out attempt or a 408, 429, 500, 502, 503 or 504, waiting as `Retry-After` says. POST and PATCH are sent once. A call still never throws on an HTTP status: it resolves `{ status, data, headers }`, and rejects only with a `TimeoutError` DOMException, the error fetch gave, or no environment to send it to.
