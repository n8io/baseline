# Security policy

## Reporting a vulnerability

Report it privately through GitHub: open the [Security tab](https://github.com/n8io/baseline/security) and choose **Report a vulnerability**. Never report a vulnerability in a public issue, pull request or discussion.

## Supported versions

Fixes ship in:

- the latest major of the `app@` template release, and
- the latest version of each `@n8io/baseline-*` package.
