# Context map

Glossaries in this repo. Use their terms in code, tests, UI copy, tickets, PRs and commits.

- [App](./apps/app/CONTEXT.md): the app template, and every project made from it. `## Architecture` is owned by the template; `## Language` by each project.

Terms about building the template itself (package, release, project) go in a new glossary linked here once they are agreed.
