# Context map

Glossaries in this repo. Use their terms in code, tests, UI copy, tickets, PRs and commits.

- [Baseline](./CONTEXT.md): building baseline itself: Packages, the Template, Projects, Releases and Template upgrades.
- [App](./apps/app/CONTEXT-MAP.md): the Template's own context map, which every Project inherits. It links the architecture terms in [apps/app/CONTEXT.md](./apps/app/CONTEXT.md), owned by the Template, and each bounded context's language, owned by that context.
