# Decisions

Each file records one decision Nate made between options, which an agent might otherwise propose again. Read them before proposing a new library, pattern or name.

Write a new one when such a decision is made: the next number, a title that states the decision, `Status: accepted, <the day it was decided>`, and one paragraph on the options, the choice and why, in three or four sentences. A decision that replaces an earlier one gets a new file, and the old one's status names it.
